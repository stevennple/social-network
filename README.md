# Social Network

Welcome to the Social Network project! This repository contains the source code for a social networking application developed using C++. The project is primarily written in C++, with additional components in Makefile.

## Introduction

This project aims to provide a fully-functional social networking application with a user-friendly interface. The application supports various social networking features such as user registration, profile management, posting updates, and more.

## Features

- User Registration and Authentication
- Profile Management
- Posting Updates and Comments
- Friend Requests and Messaging
- Notifications

## Requirements

- C++17 compatible compiler
- Make
